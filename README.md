# Подход к трансформации объектов колесного экстремального спорта (ОКЭС) в Санкт-Петербурге

## О репозитории
Данный репозиторий содержит рабочие материалы, наборы исходных данных и результаты пространственного анализа, подготовленные в рамках ВКР, посвященной разработке подхода к трансформации существующих ОКЭС в Санкт-Петербурге. 

Материалы опубликованы в целях обеспечения прозрачности исследования, верификации расчетов и демонстрации хода аналитической работы.

## Структура

Репозиторий разделен на следующие блоки:

* 📁 **`/Sociological_survey` (данные социологического опроса)**
    * Данные анкетирования пользователей ОКЭС (райдеров)
    * Материалы отражают запросы пользователей к инфраструктуре, частоту использования объектов и оценку их текущего состояния
<img width="1183" height="726" alt="Соцопрос" src="https://github.com/user-attachments/assets/ecf6b258-30b0-4ae1-a56d-bde14d643428" />


* 📁 **`/Calculations_excel` (расчетные модели и оценки)**
    * Таблицы с исходными данными и промежуточными расчетами
    * Матрицы приоритизации, расчеты индексов потенциала локации (ИПЛ) и оценки технико-функционального состояния (катабельности) объектов

* 📁 **`/Spatial_data_QGIS` (пространственный анализ QGIS)**
    * Файлы проекта и геопространственные слои
    * Включает локализацию объектов, изохроны пешей доступности, точки притяжения

* 📁 **`/Research_visuals` (графические материалы)**
    * `Approach.png` — визуальная схема подхода исследования
    * `Poster.pdf` — плакат с ключевыми выводами, картами и результатами апробации
    * `Process.png` — измененный процесс принятия решения о трансформации

## Статус материалов
Представленные файлы являются рабочим архивом (working datasets). Данные предоставляются «как есть» (as is) и иллюстрируют процесс сбора, обработки и синтеза информации, предшествующих формированию итоговых выводов, изложенных в тексте диссертации.
