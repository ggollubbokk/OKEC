Состоит из ... разделов:
1. Датасет ОКЭС в формате .xslx c названием "Датасет ОКЭС, лист..."

3. Анкета социологического опроса и ответы на него в формате .xslx
4. Плакат с исследованием в формате .pdf
5. Файлы с геопространственным анализом в QGIS в формате ...
